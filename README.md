# Study App

An Android app that helps you stay on top of your studying. It has a notes section for writing, viewing and deleting notes, a weekly Monday-to-Friday schedule you can edit, and a timer and stopwatch for tracking study sessions. The timer has quick-add buttons for 10 minutes, 50 minutes and 2 hours. Everything is reached from a navigation drawer on the home screen, which greets you with a message based on the time of day.

This is an old project, and my UI skills have come a long way since I wrote it. I've updated the app enough to build and work on modern Android, including edge-to-edge support and a new icon. I kept the UI as it was on purpose, so it can serve as a reminder of my development journey.
